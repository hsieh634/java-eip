| 編號 | 情境 | 預期 |

| E-01 | 直接更正、核准撤銷下班、核准整組作廢 | 事件內容完全不變；撤銷後再下班 → 同一筆出勤有兩筆下班事件；重打 → 新紀錄新事件 |

## E2E（`geofence.mjs`）

G0 關閉時不呼叫定位；G1 設定驗證、確認畫面、歷程；G2 過期提交；G3 畫面未更新時按下仍取最新設定；G4 拒絕／逾時／不可用／不支援／非安全來源、精度不足與重試、範圍外、定位參數、快速連按；G5 切頁後不送出、狀態改變後不送出也不變成另一個操作；G6 定位途中設定被修改 → 後端用新設定；G7 員工／主管無權限；G8 範圍外可申請、核准後仍受限；G9 ADMIN 受限（瀏覽器真正的 Geolocation API＋DevTools 模擬）；G10 手機布局。

## 未驗證

手機實機、真實 GPS 精度、HTTPS 環境、防作弊能力。
