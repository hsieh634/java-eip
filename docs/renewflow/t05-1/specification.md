# T05.1 驗收案例

執行前置：專用測試員工 Alice→Bob，Admin Carol/Dave、非指派主管 Erin；半小時時段。Clock固定台北2026-10-01，請假日2026-10-05。所有自動寫入限新建隔離庫。每案實際／版本／log於verification更新；不得將計畫標通過。

| ID | 需求／角色與步驟 | 預期HTTP／畫面與資料副作用 |
|---|---|---|
| L51-01 | Alice待審09～17，修改10～16重新送審 | 新ID／revision2，舊內容保存、舊WITHDRAWN；一個PENDING；有效仍無 |
| L51-02 | 改派／版號變動後以舊source提交、舊版審核 | 409；完整快照不變；舊版不能核准 |
| L51-03 | Bob退回，Alice新內容重送；之後組織／設定變更 | 原REJECTED／原因保留；新版本重新解析，新已送審核人不暗改 |
| L51-04 | 修改內容非法／無有效審核人／歷程故障 | 400／409／500，舊待審與歷程全部回滾 |
| L51-05 | 核准原09～17，再申請09～14 CHANGE | 待審原有效17終止、保留480分；核准後300分與有效版本+1 |
| L51-06 | CHANGE待審撤回／被退回 | 原有效與版本不變；新預留釋放、歷史保留 |
| L51-07 | 整段銷假已過日期 | 待審仍占用；核准effective=null canceled=true；舊時間分鐘不改 |
| L51-08 | CANCEL_PART縮短開始／結束 | 真子集、單側保留；差異範圍正確，核准後才生效 |
| L51-09 | 部分銷假同範圍／增加／換日期／假別／兩側縮短／零分鐘 | 400零副作用；不藉非法時間實現全文銷假 |
| L51-10 | 另一單與有效／PENDING預留衝突，相鄰、自身排除 | 衝突409；相鄰200／201；不與自身衝突 |
| L51-11 | CANCEL待審後另送相同原時段 | 409，不提前釋放；全文核准後可新單 |
| L51-12 | 同document兩個並行後續、CHANGE vs CANCEL | 恰一個新流程；資料庫唯一pending |
| L51-13 | 修改vs核准、同提交重送、重複核准 | 只一個合法序列；不把舊核准套新內容，不重複歷程 |
| L51-14 | UUID同本文／異動作／異來源／已退回撤回核准後重送 | 同本文200確認同ID；其他409；不增列／歷程，不重新解析審核人 |
| L51-15 | 來源版本／有效版本過期，另一核准取代 | 409零副作用；不改其他單 |
| L51-16 | 未登入、缺CSRF、他人、Erin、Admin越權、自審、鎖等待降級 | 401／403／404；資料不變 |
| L51-17 | 改派新類型、原指定失效、主管改動 | 保留原因／歷程；失效設定拒絕；不暗改已有指派 |
| L51-18 | 多組出勤、原事件、作廢／補登／更正／未下班／無紀錄 | 正確顯示、取得時間、無GPS；缺紀錄不自動拒絕或核准 |
| L51-19 | 出勤在看詳情後變更，刷新後審核；之後再更正 | 舊token409；新token可審核；歷程保留當時摘要不冒充現在 |
| L51-20 | 非指派者／無關日期／不相關員工證據查詢 | 404／範圍限制；無全公司出勤權限 |
| L51-21 | 有效內容切換／歷程寫入後注入失敗 | 所有列、狀態、有效版本、去重與歷程回滾 |
| L51-22 | 201 JSON／本文／缺欄位／UUID或來源／內容不符 | unknown鎖原快照、原UUID；不切另一修改表單 |
| L51-23 | 未確認重試403／5xx，成功原鍵，再放棄／401／卸載 | 拒絕仍鎖；確認只同ID；放棄需警告；卸載不更新新頁 |
| L51-24 | 同條件重查、舊GET晚到、目標失效、手機模擬 | 新查詢勝出、不fallback；空／錯誤可恢復，無橫向溢出 |
| L51-25 | 乾淨庫、V8→V9代表資料、舊APPROVED可變更 | 舊欄位逐表相同、外鍵與有效初始化正確，不製造決定 |
| L51-26 | 移除有效版本／提前銷假／忽略去重／重疊／吞歷程故障 | 對應測試必須失敗，還原後通過 |
