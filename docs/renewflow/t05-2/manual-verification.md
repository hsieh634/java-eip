以下會新增共用流程版本／操作歷程及測試假單；新發布影響之後所有新請假，個人指定仍優先。先確認這是你要採用的本機展示規則，不用刪庫或還原舊資料。

4. 登出，demo_leo→請假。先查目前清單，選未占用的未來日期（例如2026-10-22）、09:00～10:00，原因「【展示資料 T05.2 真人測試】流程第一版」，正常送出；重疊時改選合法未占用時段。詳情應有此次流程版號、關卡、送出時Iris的顯示快照。
