# T05.2 驗收案例與追溯

日期2026-10-15。角色Alice員工→Bob主管、Erin主管、Carol／Dave管理員，皆隔離庫新建合成人員。以下為實作前預期，實際結果／來源於verification更新，真人另列manual-verification，不以計畫當通過。

| ID | 目的／前置／角色／操作 | 預期API／畫面 | 資料副作用 |
|---|---|---|---|
| W01 | 無發布，ADMIN讀寫；員工／主管／匿名／缺CSRF | ADMIN成功；403／401 | 拒絕不改表 |
| W02 | 無發布，Alice送出／個人指定Erin | 原主管Bob／個人Erin | 快照無流程ID，舊優先不變 |
| W03 | 個人指定失效且共用流程有效 | 預覽問題；送出NO_VALID_APPROVER | 不fallback、零新增 |
| W04 | 草稿指定Erin，Alice正式送出 | 草稿預覽Erin、正式Bob | 草稿不影響提交 |
| W05 | 發布v1→Alice新送出；發布v2→再新送出 | 新提交各用當時版；舊待審不變 | 每次完整不同快照、指標唯一 |
| W06 | 兩ADMIN同rowVersion編輯／發布 | 一成功一409；同UUID重試確認 | 不覆蓋、不雙目前版／重複歷程 |
| W07 | 發布vs提交／改主管／停用資格並行 | 依共同鎖順序完整舊或新版 | 沒有混合來源、快照與人 |
| W08 | 指定停用／員工角色／本人／無主管 | 儲存發布資格拒絕或員工預覽／送出阻擋 | 無自審／自動ADMIN |

| W11 | 待審修改、退回重送、CHANGE、ALL／PART及改派 | 新提交解析當時版；改派保留原快照 | 原有效／鎖／歷程與去重相容 |
| W12 | Bob歷史v1、Erin後續v2新快照 | 舊巢狀JSON無新流程／人／日期 | GET零寫入、ADMIN審核不借管理權 |

| W14 | API回應遺失／非法2xx／查證404／重試409 | 保留原表單／鍵、未知提示，可查證 | 無自動重送／換鍵 |
| W15 | 草稿未存／外部版本更新／舊GET晚到 | 提示、衝突保留輸入、不覆蓋新畫面 | 不送過期資料／不宣稱成功 |
| W16 | 歷史版本及發布紀錄、嘗試UPDATE／DELETE | 完整前後／人／原因／時間；DB拒修改 | append-only／已發布不可變 |
| W17 | 乾淨V10、V9→V10代表資料與開發升級 | 舊列全欄位投影相同、舊制標示 | 無預設發布、既有展示不變 |
| W18 | 手機模擬操作表單／確認 | 可填可按、無水平溢出 | 只隔離資料 |
| W19 | 關鍵變異：漏快照／發布改舊指派／跳共同鎖 | 對應保護測試失敗 | 還原後重跑通過 |
