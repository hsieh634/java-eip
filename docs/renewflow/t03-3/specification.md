# T03.3 可執行驗收規格

第 1 輪 R1 補充：[review-round-1.md](review-round-1.md)。指定時段入口查不到原 ID 時保持待選、顯示原 ID；不得自動改另一組或補登。明選後才提交目標快照。指定入口切日期清空時間與快照並重新待選；通用入口的正常預設沿用。此補充不放寬後端合法性、權限或交易規則。

案例的實際結果／版本／證據於 verification.md 記錄；未執行不得標通過。每案使用隔離庫與專用員工。
