# Specification：T03 驗收情境

「自動」＝後端整合測試（真實 Tomcat＋PostgreSQL 測試庫＋可控 Clock）；「E2E」＝`frontend/e2e/attendance.mjs`（隔離堆疊）。

| 編號 | 情境 | 預期 | 驗證 |
|---|---|---|---|
| A-01 | 查今日，無紀錄 | 200 `NOT_STARTED` | 自動 |
| A-02 | 上班 | 200 `WORKING`；時間為伺服器時間；`workDate` 為台北日期 | 自動 |
| A-03 | 下班 | 200 `COMPLETED`；之後今日查詢為 `COMPLETED` | 自動 |
| A-04 | 未上班就下班 | 409 `CLOCK_IN_REQUIRED`；資料表無新增 | 自動 |
| A-05 | 重複上班 | 409 `ALREADY_CLOCKED_IN`；原時間不變 | 自動 |
| A-06 | 重複下班 | 409 `ALREADY_CLOCKED_OUT`；第一次下班時間不變 | 自動 |
| A-07 | 已下班後再上班 | 409 `ALREADY_CLOCKED_IN`；仍只有一筆 | 自動 |
| A-08 | 本文夾帶 employeeId／clockInAt／workDate | 被忽略；使用 Session 身份與伺服器時間 | 自動 |
| A-09 | 兩位員工隔離；查詢字串塞別人的 employeeId | 只看到／只影響自己的資料 | 自動 |
| A-10 | 未登入 | 401 | 自動 |
| A-11 | 缺 CSRF 的 POST | 403；無資料變動 | 自動 |
| A-12 | 員工被停用後，用舊 Session 打卡 | 401；Session 失效；**資料表無新增／更新** | 自動 |
| A-13 | 員工被刪除（無出勤資料）後用舊 Session | 401 | 自動 |
| A-14 | 帳號檢查發生資料庫故障 | 500 `INTERNAL_ERROR`；Session 不失效；故障排除後同一 Session 可繼續用 | 自動 |
| A-15 | 角色在資料庫被改變後用舊 Session | 401（需重新登入）；重新登入後取得新角色 | 自動 |
| A-16 | 有出勤紀錄的員工被刪除 | 資料庫拒絕（外鍵 RESTRICT），歷史保留 | 自動 |
| A-17 | UTC 日期與台北日期不同：`2026-10-01T15:59:59Z`、`16:00:00Z`、`16:30:00Z` | 業務日期分別為 10-01、10-02、10-02 | 自動 |
| A-18 | 昨日未下班；今日查詢 | `NOT_STARTED`＋`unfinishedBefore=昨日` | 自動 |
| A-19 | 昨日未下班，今日下班 | 409 `CLOCK_IN_REQUIRED`；昨日紀錄不被補上下班 | 自動 |
| A-20 | 昨日未下班，今日上班 | 200，新增今日紀錄；昨日仍為 `INCOMPLETE` | 自動 |
| A-21 | 23:50 上班、隔日 00:10 下班（跨日） | 409 `CLOCK_IN_REQUIRED`（不支援跨日班） | 自動 |
| A-22 | 日期範圍：格式錯誤／只給一個／起日大於迄日／32 日 | 400（`VALIDATION_FAILED` 或 `INVALID_DATE_RANGE`） | 自動 |
| A-23 | 恰 31 日、預設本月、含邊界、新到舊 | 200，內容正確 | 自動 |
| A-24 | 8 個並行上班 | 恰 1 個 200、其餘 409；資料表 1 筆（重複多輪） | 自動 |
| A-25 | 8 個並行下班 | 恰 1 個 200、其餘 409；資料庫的下班時間等於勝者回應 | 自動 |
| A-29 | 時鐘倒退使下班早於上班；外鍵錯誤（員工不存在） | 5xx／資料完整性例外，**不是** 409；紀錄不被改動 | 自動 |
| A-26 | V2 在乾淨庫建立；在已有 V1 與資料的庫上升級 | 表與約束存在；既有員工資料保留 | 自動 |
| A-27 | 資料庫約束：重複（員工,日期）、下班早於上班 | 資料庫拒絕 | 自動 |
| A-28 | 開發帳號密碼更新流程（測試庫） | 員工 ID 與出勤資料保留，只有密碼雜湊改變；未開啟旗標時不改 | 自動 |
| E-01 | 瀏覽器打卡全流程；首頁與出勤頁同步；按鈕狀態 | 如設計 | E2E |
| E-02 | 並行副本造成 409；回應遺失（伺服器已寫入、瀏覽器收不到）；5xx；Session 已失效（401） | 訊息可理解、狀態重新查詢、5xx 不導回登入頁、401 導回登入頁 | E2E |
| E-03 | 日期範圍查詢：有資料、無資料、起日大於迄日、超過 31 日 | 清楚的提示 | E2E |
| E-04 | 手機尺寸（390×844）：可操作、無橫向捲動 | 通過 | E2E |
