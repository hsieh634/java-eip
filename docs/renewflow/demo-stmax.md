## 2. 初始化（只在本機 dev profile）

| 設定（`.env`） | 用途 | 預設 |
|---|---|---|
| `RENEWFLOW_DEMO_STMAX_ENABLED` | 是否建立示範帳號 | `false`（關閉） |
| `RENEWFLOW_DEMO_STMAX_PASSWORD` | 六個示範帳號的共用密碼 | 空＝不建立（沒有預設密碼） |

規則（`backend/.../identity/StmaxDemoSeedRunner.java`）：
- 只有 dev profile 才有這個元件，而且必須明確設為 `true` 並提供密碼。
- 密碼只以 PasswordEncoder（bcrypt）雜湊後保存，不寫進日誌。
- **冪等**：重啟時已存在的示範帳號完全不動——不重設密碼、不改角色、不改啟用狀態；只補建缺少的。
- **碰撞時安全停止**：若帳號或員工編號已被別的員工使用，一個示範帳號都不建立，也不接管或覆寫既有帳號，並在日誌中列出碰撞。
- 既有的 `admin`／`manager`／`employee`／`developer` 與所有資料都保留。

**步驟**
1. 在專案根目錄的 `.env`（不進版控）設定：
   ```
   RENEWFLOW_DEMO_STMAX_ENABLED=true
   RENEWFLOW_DEMO_STMAX_PASSWORD=（只用英文字母與數字）
   ```
2. 重新啟動後端（dev profile）。日誌會出現「STMAX 示範帳號：新建立 […]」或「已存在（未修改）[…]」。
3. 以 `stmax_max`、`stmax_iris` 等帳號登入，密碼就是 `.env` 中 `RENEWFLOW_DEMO_STMAX_PASSWORD` 的值（用編輯器打開 `.env` 查看）。

**停用**：把 `RENEWFLOW_DEMO_STMAX_ENABLED` 改回 `false` 後重啟，之後不再建立；**已建立的帳號不會被刪除**（有關聯資料後也無法刪除）。如要停止使用某個示範帳號，由管理員停用帳號（目前沒有員工管理畫面，屬後續範圍）。

**忘記或想換密碼**：初始化刻意不重設既有帳號的密碼。本批沒有提供示範帳號的密碼重設流程。
